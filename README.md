# Mourão Visão

Plataforma de monitoramento urbano baseada em visão computacional,
geolocalização e dados para apoiar a manutenção de vias.

## Objetivo

Utilizar veículos que já circulam pelo município como pontos móveis
de coleta de dados, identificando problemas urbanos por meio de
câmeras, inteligência artificial e geolocalização.

## MVP

O primeiro MVP será focado na identificação de problemas no
pavimento, inicialmente com foco em buracos.

Fluxo:

Câmera → IA → GPS → API → Banco de dados → Dashboard → Validação → Atendimento
